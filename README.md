# UE5 第三人称战斗原型

使用 Unreal Engine 5.7.4 蓝图制作的战斗学习项目，实现玩家输入、射线命中检测、目标扣血和死亡销毁的完整流程。

## 开发环境

- Unreal Engine 5.7.4
- Windows
- Blueprint 蓝图
- Third Person 第三人称模板

## 已实现功能

- 第三人称角色移动、视角控制和跳跃。
- 鼠标左键触发攻击。
- 从摄像机位置沿画面中心方向发出射线，射程为 5000 厘米，忽略玩家自身。
- 判断命中对象是否为靶子，命中后调用扣血函数。
- 靶子初始生命值为 100，每次命中扣除 25 点。
- 使用屏幕文字显示剩余生命值。
- 生命值小于等于零时销毁靶子。

## 操作方式

| 操作 | 按键 |
| --- | --- |
| 移动 | WASD |
| 调整视角 | 移动鼠标 |
| 跳跃 | 空格 |
| 攻击 | 鼠标左键 |

使用画面中心瞄准靶子。

## 运行方式

1. 下载或克隆本仓库。
2. 使用 Unreal Engine 5.7.4 打开 `the_firstprject.uproject`。
3. 如果没有自动打开测试关卡，在内容浏览器中搜索并打开 `Lvl_ThirdPerson`。
4. 点击编辑器顶部的运行按钮，进入游戏。

## 主要蓝图

### BP_ThirdPersonCharacter

负责接收攻击输入、计算射线起点和终点、检测命中对象，并调用靶子的扣血函数。

### BP_TargetDummy

负责保存 `Health` 生命值、执行扣血、打印剩余血量，以及在生命值归零时销毁自身。

## 已完成的功能测试

- 命中靶子后，血量依次变为 75、50、25、0。
- 第四次命中后，靶子销毁。
- 攻击空气或墙壁时，靶子不会扣血。

## 学习内容与后续计划

本项目练习了蓝图变量、函数、执行线与数据线、射线检测、类型转换和条件分支。

后续计划将生命值逻辑提取为可复用组件，并尝试将该模块迁移到 C++。
